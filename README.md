## About the Project

**NED Campus Connect** is a student-focused campus management platform designed to address everyday challenges faced by students and the university community.

The platform brings multiple campus services together in one place, allowing students to report lost belongings, submit maintenance complaints, access affordable study materials, and contribute to a cleaner campus through smart waste reporting.

Instead of relying on disconnected communication channels and manual reporting, NED Campus Connect aims to provide a centralized, accessible, and user-friendly digital experience.

## Key Features

### 1. Lost & Found
- Report lost personal belongings such as ID cards, wallets, keys, and other items.
- Publish found-item reports to help reunite belongings with their owners.
- Browse and search reported items.
- Track the status of submitted reports.

### 2. Campus Maintenance & Complaints
- Report damaged chairs, broken fans, faulty equipment, and other campus issues.
- Submit maintenance requests with descriptions and supporting images.
- Track complaint progress and resolution status.
- Improve communication between students and campus administration.

### 3. Affordable Study Materials
- Discover affordable academic resources.
- Share or browse used textbooks, notes, and study materials.
- Help students access educational resources at lower costs.
- Encourage collaboration and resource sharing among students.

### 4. Smart Waste Management & Recycling
- Report overflowing or improperly managed waste bins.
- Identify recycling locations around campus.
- Encourage proper waste separation and responsible disposal.
- Promote environmental awareness and community participation.

## Project Objectives

- Digitize common campus reporting processes.
- Improve communication between students and university administration.
- Encourage responsible resource sharing.
- Promote environmental responsibility and sustainable campus practices.
- Build a more connected and accountable university community.

## Getting Started

Follow these instructions to run the project locally.

### Prerequisites

Make sure you have installed:

- Node.js (LTS recommended)
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

**2. Navigate to the project directory**

```bash
cd YOUR-REPOSITORY
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Visit:

```text
http://localhost:3000
```

> If the project uses a monorepo structure, navigate to the appropriate application directory and run the scripts defined in its `package.json`.
